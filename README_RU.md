# BEAM Control Panel

Современная self-hosted панель управления Linux-серверами с глубокой интеграцией с экосистемой BEAM (Elixir, Erlang, Phoenix).

Основная цель проекта — предоставить удобный инструмент для развёртывания, управления и мониторинга приложений Elixir/Phoenix, а также полного администрирования VPS через современный веб-интерфейс.

BEAM Control Panel ориентирована на разработчиков, DevOps-инженеров и системных администраторов, которым необходима полноценная панель управления сервером без компромиссов.

---

# Миссия проекта

Создать лучшую open-source панель управления для экосистемы BEAM.

Сделать развёртывание приложений Elixir/Phoenix таким же простым, как установка сайта через классические панели управления хостингом.
